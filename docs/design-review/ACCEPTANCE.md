## A. 拼图解压馆 / 流沙接桶

**期望图片文件**

| 文件 | 用途 |
|------|------|
| `images/sand-ui-mockup.png` | 整屏 UI 稿（图案区、传送带、手牌、道具、HUD） |
| `images/sand-sprites.png` | 桶、沙色、道具、UI 控件精灵表或分镜 |
| `images/sand-flow.png` | 玩法流程图 / 一局示意（放置→吸入→合成→通关） |

### A1. UI 稿（对照 sand-ui-mockup.png）

- [ ] 上半：目标像素图案清晰可读（不是噪点）
- [ ] 中部：传送带 / 桶槽位可见，空位与已放桶可区分
- [ ] 下部或侧边：手牌桶（颜色 + 容量）
- [ ] HUD：关卡、目标进度、连击/洒沙预算（若有）位置合理，不挡主操作
- [ ] 道具位：铲子 / 彩虹 / 磁铁（可灰态）+ 预留广告位样式可接受
- [ ] 调性：马卡龙、软圆角、治愈；非赛博硬边
- [ ] 竖屏手机比例舒适（约 9:16 或逻辑 390×700 一类）

### A2. 精灵 / 素材（对照 sand-sprites.png）

- [ ] 至少 4 种桶色，装满/未满状态可辨
- [ ] 合成前后尺寸或描边有差异
- [ ] 沙粒色与桶色一一对应
- [ ] 道具图标可识别
- [ ] 无第三方网图水印、无明显拉伸糊边

### A3. 玩法流程示意（对照 sand-flow.png）

- [ ] 图上能看出：选桶 → 放槽 → 同色吸入 → 装满合成 → 胜负条件
- [ ] 标出「同色才进」与「错色/洒沙」压力
- [ ] 与 RESEARCH 反模式一致（不是 SameGame）

### A4. 文档一致性

- [ ] 与 GDD 一页纸「胜负 / 10 关 / Juice」无冲突
- [ ] 接受 SJ1–SJ7 为编码后必验项（本阶段只确认清单存在）

### A5. 本款放行

- [ ] **拼图解压馆：UI + 精灵 + 流程示意 通过，允许该款编码**

**期望图片文件**

| 文件 | 用途 |

### B1. UI 稿（对照 duck-ui-mockup.png）

- [ ] 上方像素图案区足够大、颜色可数
- [ ] 下方鸭子池：每只可见**颜色 + 弹药数字**
- [ ] 发射台 / 选中态明确
- [ ] 按钮区含：2 倍速、升级、清除、打乱（可先占位）
- [ ] 明亮卡通 / 沙滩感，非暗黑写实
- [ ] 竖屏舒适，主操作区拇指可达

### B2. 精灵 / 素材（对照 duck-sprites.png）

- [ ] ≥4 色鸭子，Q 萌可辨
- [ ] 像素块多色 + 石头障碍样式
- [ ] 弹药数字在精灵或 UI 上足够大

## C. 向末日开炮 / 数字门

**期望图片文件**

| 文件 | 用途 |
|------|------|
| `images/doom-ui-mockup.png` | 整屏：跑道透视、大门、小队、尸潮、HUD、终点武器门 |
| `images/doom-sprites.png` | 士兵、丧尸/brute、门板、子弹、武器门 |
| `images/doom-flow.png` | 流程：开跑 → 选门 → 射击尸潮 → 终点门槛 |

### C1. UI 稿（对照 doom-ui-mockup.png）

- [ ] 伪 3D 跑道 / 高架感，黄黑警示边或等价可读边界
- [ ] 成对数字门：数字**超大**，+/-/× 颜色区分
- [ ] 底部小队清晰，在路面内
- [ ] 右侧或前方有**密集成团**尸潮示意（不是稀疏散点）
- [ ] 远处终点武器门 + need 人数可读
- [ ] HUD：人数、进度、分数/击杀，现代短视频风
- [ ] 第一眼像抖音数字门广告，而非程序员灰盒 Demo

### C2. 精灵 / 素材（对照 doom-sprites.png）

- [ ] 士兵统一设计（如蓝盔战术服 + 枪），非纯色方块人主外观
- [ ] 丧尸绿皮 + 壮汉 brute 两档可辨
- [ ] **脚底锚点明确**（精灵站立，不是飘着的团）
- [ ] 门半透明板 + 粗描边 + 大字方案可接受
- [ ] 无扭曲拉伸、无半透明糊成一团当主尸潮

### C3. 玩法流程示意（对照 doom-flow.png）

- [ ] 自动前进 + 左右拖选门
- [ ] 自动开火，人数影响火力有标注
- [ ] 尸潮在**路面上**涌来（图注写明脚贴地）
- [ ] 失败：碰尸 / 人数 0 / 终点不够人
- [ ] 标注本期**无基地 SLG**
- [ ] 反模式已避开：挡路人群、漂浮僵尸、错投影、小队冲出桥面（图上无这些错误示范，或有「禁止」叉标）

### C4. 文档一致性

- [ ] 与 DOOM V2 / RESEARCH 反模式 Z-A1–Z-A8 一致
- [ ] 接受 ZJ1–ZJ8 与「统一投影、脚底贴路、横向夹紧」为编码硬约束

### C5. 本款放行

- [ ] **向末日开炮：UI + 精灵 + 流程示意 通过，允许该款编码**
