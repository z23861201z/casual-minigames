## 游戏 A — 拼图解压馆（流沙接桶）

**路径（实现时）：** `games/sand-bucket/`  
**一句话：** 像素图案碎成彩沙，重力下落；在传送带上放同色桶接住、装满合成，把图案收干净。  
**核心幻想：** 「沙沙地接住、合成更大桶、一口气灌满图案超解压。」

### 核心循环

```
看图案 → 选手牌桶 → 点传送带空位 → 同色沙吸入
→ 装满可合成更大桶 → 图案颜色清空 / 回填完成 → 下一关
```

1. 开局展示目标像素图 + 手牌若干彩色桶（色 + 容量）。
2. 沙粒从图案位重力下落；玩家把桶放到传送带槽位。
3. 仅同色沙进入对应桶；错色按规则洒出或拒收（需在关卡表写明）。
4. 两个**已满、同色、同容量**的桶可合成容量更大的桶。
5. 道具（可选）：铲子 / 彩虹桶 / 磁铁；用尽可出本地「广告位」UI（不接真广告）。

### 操作

| 输入 | 行为 |
|------|------|
| 点击手牌桶 | 选中（高亮） |
| 再点传送带空槽 | 放置 |
| 点击两只可合成桶（或合成按钮） | 合并 |
| 点击道具图标 | 使用一次 |
| 暂停 | 打开菜单 |

移动端：全触摸；桌面可鼠标点击。

### 胜 / 负

| 结果 | 条件 |
|------|------|
| **胜** | 目标图案对应颜色的沙全部收集完毕（或回填完成，按关卡定义） |
| **负** | 洒沙超过预算 **或** 无空位且仍有沙下落 **或** 放置次数用尽（若该关启用上限） |

## 游戏 B — 消除我可以（鸭子发射）

**路径（实现时）：** `games/duck-pop/`  
**一句话：** 选带颜色与弹药的鸭子，打上方同色像素；碎块流体塌落，清空图案过关。  
**核心幻想：** 「这只鸭子刚好够打穿这一列同色，塌下来真爽。」  
**明确不是：** SameGame / 连连看。

### 核心循环

```
看像素图案 + 鸭子池 → 点鸭子上发射台 → 选列/方向发射
→ 只伤同色 → 碎块下落压实 → 弹药/道具调度 → 清空通关
```

1. 上方：像素积木图案（可含石头障碍）。
2. 下方：鸭子池（每只 = 颜色 + 弹药整数）。
3. 点鸭子 → 点目标列（或发射台确认）→ 向上射击。
4. 命中同色：像素碎成粒子下落并压实；异色：不伤（打不中不扣弹药为推荐默认）。
5. 按钮：2 倍速 / 升级 / 清除 / 打乱。

### 操作

| 输入 | 行为 |
|------|------|
| 点鸭子 | 选中 |
| 再点列或发射 | 开火 |
| 「2倍速」 | 动画与下落加速 |
| 「升级」 | 本关弹药或穿透临时增强（次数有限） |
| 「清除」 | 清一行或一种辅助清除 |
| 「打乱」 | 重排剩余颜色（次数有限） |

### 胜 / 负

| 结果 | 条件 |
|------|------|
| **胜** | 可消除像素全部清空（石头可保留或需特殊关清除，关卡表定义） |
| **负** | 鸭子弹药耗尽且场上仍有可消像素，且无可用道具 |

### 10 关难度草图

| 关 | 图案 | 颜色 | 障碍 | 鸭子配置要点 | 教学点 |
|----|------|------|------|--------------|--------|
| 1 | 矮墙 3 色 | 3 | 无 | 弹药充裕 | 选色射击 |
| 2 | 小像素画 | 3 | 无 | 弹药刚好 | 规划弹药 |
| 3 | 列较长 | 4 | 无 | 引入倒塌链 | 塌落阅读 |
| 4 | 中间石头 | 4 | 石×2 | 绕射/打侧列 | 障碍 |
| 5 | 缺口多 | 4 | 石 | 弹药偏紧 | 打不中不扣 |
| 6 | 宽屏图案 | 5 | 石 | 首次「打乱」 | 重排 |
| 7 | 高塔 | 5 | 石多 | 「清除」一行 | 救急 |
| 8 | 混合炮灰层 | 5–6 | 石 | 「升级」穿透 | 强化 |
| 9 | 伪对称易误判 | 6 | 石 | 倍速常用 | 速度压力 |
| 10 | Boss 像素画 | 6 | 石阵 | 全按钮限次 | 综合 |

## 游戏 C — 向末日开炮（数字门跑酷）

**路径（实现时）：** `games/doom-gates/`  
**一句话：** 自动狂奔，左右滑选数字门涨人数，自动开火清路面尸潮，终点武器认人数。  
**核心幻想：** 「选对门人暴涨，弹幕变墙，尸潮被扫穿，撞开终点武器门。」  
**本期不做：** 基地 SLG。

### 核心循环

```
开局小队 N → 自动前进 → 左右拖选门（+/−/×/÷）
→ 自动射击清尸潮 →（可射门改数字）→ 终点武器门 need 人数 → 通关 / 失败
```

1. 伪 3D 跑道自动前进；玩家只管横向。
2. 成对（或同排）大门，撞入一扇改小队人数。
3. 人数↑火力↑（弹道数/射速/伤害）。
4. 丧尸波次脚踩路面成潮涌来；只有**碰触小队**或**人数归零**或**终点不够人**才失败。
5. 终点武器门显示 need；可选：射击降低门槛（不低于原 need 的 55%）。

### 操作

| 输入 | 行为 |
|------|------|
| 单指左右拖 / ←→ / A D | 小队横向移动（夹紧在路面内） |
| （自动） | 前进、开火 |
| P / Esc / 暂停键 | 暂停 |
| 空格 / 开始按钮 | 开始、继续 |

### 胜 / 负

| 结果 | 条件 |
|------|------|
| **胜** | 到达终点且人数 ≥ 武器门 need（或击败关底 Boss，若该关启用） |
| **负** | 人数被门减至 0 **或** 丧尸碰到小队 **或** 终点人数不足 |

| 关 | 开局人数 | 门类型 | 尸潮 | 终点 need | 教学点 |

| 2 | 6 | + / − | 小潮 | 12 | 躲减门 |
| 3 | 8 | + / × | 中潮 | 20 | 乘法爽感 |
| 4 | 8 | +/−/× | 中潮 + 射门教学 | 24 | 射击改门 |
| 5 | 10 | 全运算 | 双波 | 35 | 规划乘区 |
| 6 | 10 | 高压 −/÷ 并置 | 密潮 | 40 | 决策压力 |
| 7 | 12 | 可射门密集 | 密潮 | 55 | 射门降压 |
| 8 | 12 | 混合 | 潮 + brute | 70 | 精英尸 |
| 9 | 15 | 高压 | 连续潮 | 90 | 火力管理 |
| 10 | 15 | 全要素 | Boss 潮 + 武器门 | 120 | 综合验收 |

关卡数据建议字段：`gates[]`、`zombieWaves[]`（中心 x/z、count、hp、kind）、`finish{need,name}`。
