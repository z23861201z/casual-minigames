## 一、拼图解压馆（流沙接桶 / Sand Loop 风格）

### 1.1 品类与竞品笔记

| 参考 | 平台常见形态 | 可拿走什么 | 不要抄什么 |
|------|--------------|------------|------------|
| 流沙消除 / 沙漏接色桶类广告 | 抖音超休闲开屏 | 重力沙粒、传送带桶位、同色才进、装满合成、像素图案目标 | 网图素材、他人关卡图 |
| Sand Sort / Color Sand 变体 | TikTok / App Store 休闲 | 「先看图案 → 再管接沙」的叙事；马卡龙治愈色 | 纯试管倒色（无图案） |
| 像素填色解压类 | 短视频「解压馆」标签 | 软圆角 UI、连击、小道具（铲/磁铁） | 重度关卡编辑器 |

**竞品共性（必须对齐的「感觉」）：**

1. 上半屏是**可读的像素图案**（水果、动物、甜品等），不是抽象噪点。
2. 沙子是**粒子**，有重力、堆叠、倾泻感；不是整块色块瞬移。
3. 中间或下方是**传送带 / 槽位**，玩家点手牌桶 → 点空位放置。
4. **同色才进桶**；错色沙洒出或堵住是失败压力源之一。
5. 装满的同色同容量桶可**合成更大桶**（容量升级感）。
6. 目标是把图案对应颜色的沙**全部收集并回填/清空图案**。
7. 视觉：马卡龙柔和、软阴影、治愈；音效偏「沙沙 + 叮当」。

### 1.2 必须有的手感（Must-have Feel）

- [ ] 沙粒下落可见、堆在桶口再吸入（或明显「吸进」反馈）
- [ ] 放置桶有「咔哒」到位感；装满有涨满动画 + 数字/进度环
- [ ] 合成时两桶合并放大、颜色加深或描边变粗
- [ ] 连击时 HUD 闪光、粒子增多
- [ ] 失败清晰：洒沙超预算 / 无空位 / 放置次数用尽（若启用上限）
- [ ] 道具：铲子（清错沙）、彩虹桶（临时通色）、磁铁（吸同色）— 可先本地免费次数 + 广告位 UI 预留

### 1.3 反模式（Anti-patterns）— 验收时一票否决

| ID | 反模式 | 为何不行 |
|----|--------|----------|
| S-A1 | 做成 SameGame / 点同色块消除 | 品类错位，用户已驳回 |
| S-A2 | 沙子是整格瞬删，无重力粒子 | 没有「流沙」解压感 |
| S-A3 | 桶可接任意颜色 | 决策与同色约束消失 |
| S-A4 | 无传送带/槽位，桶随便点地图 | 不像接桶广告素材 |
| S-A5 | 无合成，只有单一容量 | 缺少中期成长爽点 |
| S-A6 | UI 硬边高对比赛博风 | 与「解压馆」治愈调性冲突 |
| S-A7 | 图案不可读（糊成一团） | 目标不清晰 |

### 1.4 验收用一句话

> 「看起来像抖音流沙接桶广告：沙往下掉，同色桶接着，装满能合成，最后把像素图案收干净。」

## 二、消除我可以（鸭子发射 / Duck Pixel · Cube Blast 风格）

### 2.1 品类与竞品笔记

| 参考 | 平台常见形态 | 可拿走什么 | 不要抄什么 |
|------|--------------|------------|------------|
| Cube Blast / 颜色方块射击类 | TikTok 射击消除广告 | 下方「弹药单位」带颜色+数量；向上打同色；打穿后塌落 | 三维物理引擎重依赖 |
| Duck / 动物发射像素 | 抖音「鸭子打方块」素材 | Q 萌角色池、点选上发射台、弹药数字 | 他人鸭子 IP 造型 |
| 非 SameGame | — | — | **点击相邻同色消除、连连看、翻牌** |

**竞品共性：**

1. **上方**是像素积木 / 像素画图案；**下方**是角色池（鸭子）带**颜色 + 弹药数**。
2. 玩家点选一只鸭子放到发射位，向指定列/方向发射，**只消灭同色像素**。
3. 击碎后碎块呈**流体/粒子下落并压实**（collapse），不是 SameGame 的「邻接组消失」。
4. 打不中同色通常**不扣或反馈弱扣**（以广告为准：打不中不扣弹药更友好）。
5. 辅助按钮常见：2 倍速、升级（弹药/穿透）、清除一行、打乱颜色。
6. 美术：明亮卡通、沙滩/糖果感、Q 萌。

### 2.2 必须有的手感

- [ ] 鸭子池可读：颜色一眼认、弹药数字大
- [ ] 发射轨迹清晰（弹道或光束），命中同色爆开
- [ ] 不同色穿透或停下规则在 UI 上说清（建议：只伤同色，遇异色停下或穿过但不伤）
- [ ] 倒塌/压实有链式下落，残留空洞被上方块填上
- [ ] 石头/障碍挡住弹道（增加关卡阅读）
- [ ] 清空图案 = 通关；无解或弹药耗尽且无法清完 = 失败（或给打乱/清除兜底）

### 2.3 反模式 — 一票否决

| ID | 反模式 | 为何不行 |
|----|--------|----------|
| D-A1 | **做成 SameGame**（点相邻同色消除） | 用户明确驳回 |
| D-A2 | 无弹药数字，无限乱射 | 缺少资源规划 |
| D-A3 | 无流体倒塌，方块瞬删留空 | 不像 Cube Blast |
| D-A4 | 鸭子无颜色区分 | 决策消失 |
| D-A5 | 操作成「拖拽连线消除」 | 品类错位 |
| D-A6 | 暗黑写实鸭子 | 与明亮卡通冲突 |

### 2.4 验收用一句话

> 「下方选带弹药的鸭子，打上方同色像素；碎块往下塌，不是点格子消的 SameGame。」

## 三、向末日开炮（数字门跑酷 / 枪火尸潮）

### 3.1 品类与竞品笔记

| 参考 | 平台常见形态 | 可拿走什么 | 不要抄什么 |
|------|--------------|------------|------------|
| 枪火尸潮 / 冲门冲冲冲 / Z-Squad / Z Route 等广告 | 抖音 / TikTok 数字门跑酷 | 自动前进、单指左右拖、成对大门 +/−/×、自动开火、尸潮、终点武器门槛 | 他人角色与关卡照搬 |
| Count Masters / Crowd Run 变体 | 国际超休闲 | 人数可视化、撞门涨人 | 纯撞人无射击的旧抽象结算作主体验 |
| 旧版「力量比大小瞬间消失」 | 本仓库已归档 | — | **禁止作为主体验** |

**竞品共性（强制对齐）：**

1. **自动前进跑道** + **单指左右拖**（小队始终在路面宽度内）。
2. **成对数字门**（黄/蓝等大字 +/−/×/÷）；可射击改门数字为差异化加分。
3. **自动射击**；人数↑ → 弹幕/伤害↑。
4. **丧尸成潮**：密集成群、体量大、脚底贴路面向玩家涌来。
5. **终点**：人数门槛武器门或巨大 Boss；人不够失败。
6. 视觉：伪 3D 高架/公路、黄黑警示边、高饱和发光门、卡通士兵。

**本期范围：** 只做跑酷关卡模块，**不做基地 SLG / 建造 / 出征养成**。

### 3.2 必须有的手感

- [ ] 左右拖跟手，小队不卡死中线、不冲出桥面
- [ ] 门数字超大可读；过门后人数跳动 + 浮动字飞向 HUD
- [ ] 开火连续可见；人多时弹幕变密
- [ ] 尸潮远距离成团可读，近处更大；击杀有粒子/飘字/轻震屏
- [ ] 失败仅：人数归零 **或** 丧尸碰到小队 **或** 未达终点门槛
- [ ] 终点武器门显示 need 人数；可射击降低门槛（若做差异化，需有下限，如不低于原需求 55%）

### 3.3 反模式 — 一票否决（含历史驳回点）

| ID | 反模式 | 为何不行 |
|----|--------|----------|
| Z-A1 | **人群挡路 / 堵桥**（己方或中立 NPC 挡住前进） | 短视频素材忌讳；破坏奔跑节奏 |
| Z-A2 | **漂浮僵尸**（脚底不在路面、叠楼、飞在空中） | 用户明确驳回「素材像一坨屎 / 坐标错」 |
| Z-A3 | **世界坐标→屏幕投影不一致**（人/尸/门/子弹各用一套公式） | 导致错位、穿模、飘移 |
| Z-A4 | 小队画到桥外 / 偏出路面 | 跟手失败 |
| Z-A5 | 抽象「力量 ≥ HP 瞬间消失」无射击无可见尸潮 | 旧玩法，已驳回 |
| Z-A6 | 几何方块人当主外观；僵尸糊成半透明团 | 不像广告级卡通 |
| Z-A7 | 本期做基地 SLG | 范围外 |
| Z-A8 | 单个稀疏散点僵尸当「潮」 | 没有压迫感与广告感 |

### 3.4 验收用一句话

> 「像抖音数字门广告：拖着小队自动跑，撞门涨人，对着路上成潮的丧尸扫射，终点武器认人数；僵尸脚踩在路上，绝不飘、不挡桥。」

## 四、跨三款的通用约束

1. **纯静态** HTML/JS/Canvas，零构建；素材程序化/Canvas 生成，勿下网图。
2. **移动优先**竖屏；触控为主，键盘为辅（数字门）。
3. **编码前**必须通过 `ACCEPTANCE.md` 勾选（UI 稿、精灵、流程示意）。
4. 旧原型（SameGame、抽象 Number Gate）仅存 `archive/`，不得作为本三款主体验。
5. 调研仅作玩法/架构参考，不复制第三方素材与大段源码。
