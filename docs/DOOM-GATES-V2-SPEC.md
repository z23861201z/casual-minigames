# 向末日开炮 · V2 重做规格（对标抖音广告素材）

用户驳回 V1：素材像「一坨屎」、僵尸丑且不像精灵、世界坐标→屏幕投影错误（漂浮/叠楼）、小队偏出路面。必须整条重做：需求→UI→玩法→编码→验证→验收。本期仍只做跑酷关卡模块（不做基地 SLG）。

## 1. 对标结论（抖音 / TikTok 超休闲数字门）

共性模板（枪火尸潮、冲门冲冲冲、酷跑枪神、Z-Squad、Z Route 广告等）：
1. **自动前进跑道** + **单指左右拖**（跟手，小队始终在路面内）
2. **成对数字门**（黄/蓝大字 +/−/×/÷）；可射击改门数字是差异化加分项
3. **自动射击**；人数↑ → 弹幕/伤害↑
4. **丧尸必须成「潮」**：密集成群站在路面上朝玩家涌，体量大、可读、站立脚底贴路，禁止单个漂浮错位
5. **终点**：人数门槛武器门 / 或巨大 Boss 血条；人不够即失败
6. **视觉**：伪 3D 高桥/公路、黄黑警示边、雾城天际线、高饱和发光门、卡通 3D 风士兵（多从背后/3/4 视角）、现代短视频 HUD

用户参考截图要点（docs/refs/doom-gates.jpg）：
- 高架桥透视、警示条边
- 半透明发光大门，数字超大
- 远处武器门 + 需求人数
- 右侧密密麻麻尸潮团块（不是稀疏散点）
- 底部跟手士兵清晰可读

## 2. 玩法循环（至少 10 关渐进）

每关：开局小队 N → 自动前进 → 左右选门涨人/躲减员 → 中途尸潮用火力清 → 可射门改数字 → 终点武器门（need 人数）通关。
爽感：弹幕密度随人数、击杀飘字、震屏、门数字弹出飞向人数、连击、音效。
失败：人数归零 / 未达终点门槛。
关卡 JSON：gates[], zombieWaves[]（集群中心 x/z、count、hp、kind）、finish{need,name}。

## 3. UI / 美术强制标准

- **禁止**：几何方块人兜底当主外观；僵尸脚底不在路面；半透明糊成一团；素材扭曲拉伸。
- **士兵**：统一角色设计（蓝盔/战术服/枪），提供 idle/run/shoot 帧或高质量伪 3D Canvas 绘制；小队呈弧形阵列贴地，人数多时显示「前排实体 +N」。
- **僵尸**：绿皮丧尸 + 壮汉 brute 两档；walk 循环；**绘制锚点=脚底**；同波次紧密排布成墙/楔形，近处更大。
- **门**：半透明板 + 粗描边 + 超大数字；左右颜色固定（加黄/减红/乘紫等）。
- **场景**：路面贴线、黄黑边、两侧简模楼、雾天际；性能 60fps 移动端。
- 素材用脚本/Canvas 原创生成（tools/），勿下网图；可替换 assets/doom-gates/**。

## 4. 技术

路径：games/doom-gates/ 纯静态 Canvas+JS。投影公式必须统一：世界 (x,z) → 屏幕，**所有实体（人/尸/门/子弹）共用同一 project**，脚底/门底对齐 sy。横向 x∈[-0.85,0.85] 映射到路面宽度内，禁止画到桥外。
测试：core-test 覆盖门运算、射击改门、碰撞、通关失败；headless 冒烟可开。
